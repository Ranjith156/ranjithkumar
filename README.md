# Git & Version Control Practical Exercises

A small static website for practising Git and GitHub during a 15-day internship.

## Run locally
1. Open this folder in VS Code.
2. Open `index.html` in a browser (or use the Live Server extension).
3. Click the button to verify JavaScript works.

## Suggested Git practice
- Initialise a repository and inspect `git status`.
- Stage files and create the first commit.
- Create a feature branch, edit the page, and commit the change.
- Merge the feature branch into `main`.
- Create an empty GitHub repository and connect it as `origin`.
- Push and pull changes.
- Optionally practise resolving a merge conflict in a separate test branch.

See the accompanying step-by-step DOCX guide for commands and screenshots to capture.
